# توصيف إعادة البناء

> سجل النسخة الأولى المستندة إلى اللقطات. منذ 17 أكتوبر أصبحت الحسابات وحفظ الصورتين موجودة فعلياً. الحالة الأحدث والقرارات في [PROJECT_REFERENCE.md](PROJECT_REFERENCE.md).

## الهدف

مساعدة المستخدمة على بناء إطلالة: صورتها → اختيار ملابس → تسريحة ولون شعر → مكياج → مراجعة وحفظ. الأصل، وفق وصف المستخدمة، يقترح فساتين من dataset ويعرض/يطبق المكياج وينتهي بصورة كاملة، باستخدام نموذج Gemma محلي.

## قرارات النسخة الأولى

Node.js وخادم HTTP مدمج دون dependencies، وHTML/CSS/JavaScript. لا تثبيت نماذج ولا خدمات مدفوعة. الواجهة مستلهمة من اللقطات وليست نسخة مطابقة بكسلياً. رسومات الملابس والشعر مرجعية مرسومة في SVG، وليست صوراً مولّدة أو عناصر من dataset. تحكم المكياج يطابق أنواع المدخلات المؤكدة، ومعاينته ألوان فقط: لا يدعي وضع مكياج على الوجه. إخراج لوحة الاختيارات بديل مرحلي عن التوليد غير الموصول.

اللقطات الإضافية محفوظة في `references/`: [المستشارة](references/demo-04s-gemma.png)، [المكياج](references/demo-50s-makeup.png)، [النهاية](references/demo-77s.png).

## الفصل بين المكونات

1. **الواجهة:** الاختيارات والصور في ذاكرة المتصفح، مع تصدير PNG/JSON.
2. **الاقتراحات:** `POST /api/suggestions` يستقبل `{occasion, preference}` فقط ويرجع `{text}` من Ollama عند إعداده، أو 503 ورسالة واضحة. `GET /api/status` يوضح الإعداد، ولا يثبت سلامة خدمة Ollama.
3. **الكتالوج:** ملف JSON يربط IDs بصور محلية. Fashionpedia API أداة قراءة/تقييم وليست نموذج توليد. تجهيز masks واستيراد عينة فعلية عمل لاحق.
4. **التجربة الافتراضية:** غير موصولة. العقد المقترح: صورة شخص + صورة/قناع القطعة + خيارات الشعر/المكياج → jobId → حالة/خطأ/صورة نتيجة. يجب اختيار محرك فعلي واختبار الحفاظ على الهوية والملابس قبل تفعيل زر توليد.

## حدود النسخة

لا تخزين دائم أو حسابات، لا استدلال بصري، لا اقتراحات مشتقة من الصورة، ولا دمج مولّد على الوجه والجسم. تنزيل لوحة تضم الصور والاختيارات يعمل بشكل مستقل. ربط Ollama قابل للتجربة بعد توفير نموذج؛ لا يُعتبر موصولاً لمجرد وجود الكود.

## معايير التسليم الأول

فتح الواجهة محلياً، رفض صورة غير صالحة، المرور بجميع الخطوات مع تعديل الاختيارات، إنتاج لوحة PNG وJSON، رسائل صريحة عند عدم اتصال المستشارة، وخلو العرض من ادعاء وجود صورة مولّدة. يُوثق ما تم فحصه في `VERIFICATION.md`.
