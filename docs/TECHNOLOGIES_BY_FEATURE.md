# التقنيات المستخدمة حسب الميزة — Smart AI Beauty

الإصدار: 0.8.0 · تاريخ التوثيق: 17 أكتوبر 2026.

## الفكرة العامة

موقع عربي باتجاه RTL يساعد المستخدمة على تجهيز إطلالة لمناسبة: يربط نوع المناسبة والمكان والطقس بقطع من الكتالوج وخزانتها، ثم يتيح اختيار الشعر والمكياج وتوليد صورة تقريبية للإطلالة. توجد مستشارة نصية للمحادثة، بينما توليد الصور له محرك مستقل.

| الاختبارات | Node Test Runner، `assert`، طلبات HTTP واختبارات عزل الحسابات | 18 اختباراً آلياً في الإصدار الحالي، مع فحص متصفح واختبارات فعلية لـGemini وCloudflare | فحص الجودة على أمثلة لا يثبت نجاح كل صورة أو كل سؤال |
| التشغيل بنقرتين | Batch على سطح المكتب + `launch.mjs` + Node child_process | التحقق من الخادم، تشغيله في الخلفية عند الحاجة، ثم فتح المتصفح | يتطلب Node.js ومسار المشروع الحالي؛ السجل في runtime/launcher.log |

## التسريحات العشر

تموجات طبيعية، شعر مرفوع للخلف، ضفيرة جانبية، ذيل حصان مرتفع، كعكة منخفضة، كاريه قصير، بيكسي قصير، كيرلي كثيف، نصف رفعة، وشعر مالس طويل.

## مسار البيانات باختصار

```text
المتصفح → خادم Node → SQLite للحفظ الخاص
                    → Open-Meteo للموقع والطقس
                    → Gemini للمحادثة والاقتراح النصي
                    → Cloudflare / FLUX لتحرير الصور عند الموافقة

المعاينات المحلية: المتصفح → MediaPipe + WASM + Canvas
```

الموقع يعتمد على خدمات خارجية وقت المحادثة والاقتراح والتوليد والطقس؛ وجود الملفات محلياً لا يجعله يعمل بالكامل دون إنترنت. ملفات MediaPipe والنماذج المستخدمة محلياً مرفقة بالمشروع.

## ما لم نستخدمه في التشغيل الحالي

- لا تدريب أو Fine-tuning لنموذج صور خاص بالمشروع.
- لا نموذج Gemma/Ollama محلي معتمد حالياً، رغم وجود محول أولي سابق.
- مسار Hugging Face السابق لتجربة الملابس متوقف؛ الربط الحالي للصور Cloudflare.
- لا RAG أو قاعدة بيانات متجهات؛ البيانات الحالية محدودة ويُرسل منها سياق منظم مباشرة.
- لا استخراج دقيق لشكل الجسم أو لون البشرة أو قياسات الملابس من الصور.
- لا Dataset كبيرة جديدة في هذا الإصدار؛ توسعة البيانات خطوة لاحقة.
