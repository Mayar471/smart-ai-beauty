# Legacy: IDM-VTON try-on experiment

The earlier garment try-on route through a Hugging Face Space (IDM-VTON). It was retired in favour of
Cloudflare Workers AI and is **not** used by the application or its test suite.

It is kept for reference only. To run it you would need `npm install @gradio/client pngjs` and to restore
the `/api/tryon` routes from version 0.9.0.
